# DustNav

Sistema local de navegação de sobrevivência. Compara corredores por distância,
terreno, zonas de risco e pontos de apoio, e apresenta alternativas seguras,
equilibradas e rápidas quando o grafo oferece caminhos distintos.

## Executar

```bash
cd backend
npm start
```

A aplicação abre em `http://localhost:3000/`.

## Testar

```bash
cd backend
npm test
```
